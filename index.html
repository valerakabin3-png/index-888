Розділ 1. Вступ до гіпертексту

Гіпертекст — це текст, який містить посилання на інші тексти або фрагменти всередині самого себе. Саме завдяки гіперпосиланням звичайні текстові документи перетворилися на Всесвітню павутину (World Wide Web), якою ми користуємося щодня. Основним тегом для створення посилань у мові HTML є тег з обов'язковим атрибутом href.

Коли документ має великий обсяг тексту, користувачеві незручно постійно крутити коліщатко миші вгору та вниз. Для вирішення цієї проблеми використовують так звані «якірні» посилання. Вони дозволяють миттєво перестрибнути до потрібного абзацу або заголовка. Для цього елементу, на який ми хочемо перейти, задається унікальний атрибут id, а в посиланні вказується його назва зі знаком решітки # попереду.

Крім звичайного підкресленого синього тексту, сучасні сайти оформлюють посилання у вигляді кнопок. Це робить інтерфейс більш інтуїтивним та зручним для натискання як мишкою на комп'ютері, так і пальцем на екрані смартфона. Створити таку кнопку можна власноруч за допомогою CSS, згенерувати на спеціальних онлайн-сервісах або взяти готову з CSS-фреймворків.

Розділ 2. Коротка історія розвитку HTML та CSS

Мова розмітки гіпертексту HTML була створена британським вченим Тімом Бернерсом-Лі на початку 1990-х років у стінах Європейської організації з ядерних досліджень (CERN). Спочатку вона налічувала менше двадцяти тегів і призначалася виключно для обміну науковою документацією між фізиками з різних університетів світу.

Перші веб-сторінки виглядали дуже просто: білий або сірий фон, чорний текст шрифтом Times New Roman і сині підкреслені посилання. Жодних анімацій, градієнтів чи красивих кнопок тоді не існувало. Усі спроби прикрасити сторінку робилися прямо в HTML за допомогою тегів на кшталт або таблиць, що робило код громіздким і важким для підтримки.

Ситуація кардинально змінилася з появою каскадних таблиць стилів — CSS (Cascading Style Sheets). Це дозволило відокремити структуру документа (HTML) від його зовнішнього вигляду (CSS). Тепер розробники отримали повний контроль над кольорами, відступами, тінями, заокругленням кутів та поведінкою елементів при наведенні курсора (псевдоклас :hover). Сьогодні стандарт HTML5 у поєднанні з CSS3 дозволяє створювати повноцінні веб-додатки, які нічим не поступаються звичайним програмам на ПК.

Для прискорення роботи програмісти часто використовують генератори коду (наприклад, CSS Button Generator) або підключають готові бібліотеки стилів, такі як Bootstrap чи Tailwind CSS, де вже прописані класи для десятків варіантів кнопок, форм та меню.
