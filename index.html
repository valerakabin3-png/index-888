1. Анімація за допомогою тегу

Тег створює бігучий рядок або рухомий елемент без написання CSS-анімацій. Наведіть курсор на рядок, щоб він зупинився (за рахунок подій onmouseover та onmouseout).

Увага! Практична робота з веб-розробки — студент групи ІПЗ-24-1 вивчає анімацію в HTML та CSS!
Рух туди-сюди (behavior="alternate")

Примітка: у сучасному стандарті HTML5 тег вважається застарілим (deprecated), тому в реальних проєктах замість нього використовують CSS або JavaScript.

2. Анімація за допомогою властивості CSS animation

Властивість animation разом із правилом @keyframes дозволяє плавно змінювати координати, колір, масштаб і тіні елементів.
